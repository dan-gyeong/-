# companies.csv 열 설명

기업/직무 데이터는 **직무 1개 = 1행**입니다. 같은 회사가 직무를 여러 개 채용하면 행을 여러 개 만들고, `booth_no`·`company`는 그대로 반복해서 적습니다.

**절대 원칙**
- 공고에 없는 값은 절대 추측해서 채우지 않습니다. 모르면 그냥 빈칸으로 둡니다. 앱 화면에는 빈칸이 자동으로 "정보 없음"이라고 표시됩니다.
- `age_note`에는 기업이 공고에 실제로 적은 연령 관련 문구만 옮겨 적습니다. 앱은 이 값을 이유로 추천에서 제외하지 않습니다.
- Excel에서 편집할 때 특히 아래 규칙을 지켜주세요: 값 안에 쉼표(,)가 있으면 반드시 그 값 앞뒤를 큰따옴표(")로 감싸세요. Excel로 저장하면 자동으로 처리되니 보통은 신경 쓰지 않아도 됩니다.

| 열 이름 | 설명 | 입력 규칙 | 예시 |
|---|---|---|---|
| job_id | 직무 고유번호. 앱이 자동 채번하므로 새 행을 추가할 때는 `부스번호-순번` 형식으로 직접 채워도 됩니다 | `booth_no-순번` | `A-12-1` |
| booth_no | 부스번호 | 행사 배치도의 부스번호 그대로 (aT센터는 1개 층만 사용하므로 층 구분 없음) | `A-12` |
| company | 기업명 | 공고 그대로 | `(주)○○` |
| industry | 업종 | 공고에 업종 표기가 있을 때만 입력. 없으면 빈칸 | `제조` |
| recruit_type | 모집구분(원문) | 참여기업 등록 자료의 "모집구분"을 그대로 옮김 | `인력채용` / `채용정보제공` |
| job_title | 채용 직무명 | 공고 원문 그대로 | `시설관리원` |
| job_family | 직무군(=업종과 동일한 참여기업 등록 자료의 대분류) | `industry`와 동일한 값. 행사 주최측이 부스 구역을 나눈 기준과 동일 | `조리·돌봄·시설관리` |
| headcount | 채용인원 | 숫자만 | `3` |
| work_area | 근무지(시군구) | 서울 25개 자치구 기준 표기 권장 | `서울 노원구` |
| employment_type | 고용형태(원문) | 공고 원문 그대로 (정규직/계약직/프리랜서/파견직 등 제한 없음) | `정규직` |
| work_day | 근무일(원문) | 공고의 "근무일"을 그대로 옮김 | `주5일` |
| work_hour | 근무시간(원문) | 공고의 "근무시간"을 그대로 옮김 | `8시간 이상` |
| work_schedule | 근무형태(요약) | `work_day`+`work_hour`를 합쳐 자동 생성. 앱의 근무형태 매칭 점수에 쓰임 | `주5일 / 8시간 이상` |
| pay_text | 급여(공고 표기 그대로) | 원문 그대로 옮김. 시급/월급 단위를 임의로 바꾸지 않음 | `월 250만원` |
| pay_monthly_min | 월급 환산 하한(숫자) | 공고에 월급이 명시된 경우에만 숫자로 입력. 시급제 등 환산이 불확실하면 빈칸 | `2500000` |
| required_license | 필수 자격·면허 | "자격증 소지자(필수)"처럼 명확한 경우만 채움. 하드 필터(미보유 시 추천 제외)로 쓰이므로 애매하면 반드시 빈칸으로 둠. 여러 개면 세미콜론(;) 구분 | `요양보호사` |
| preferred_license | 우대 자격 | `preference_note` 원문에서 자격증·면허 키워드를 넓게 추출(가점 요소라 하드 필터보다 관대하게 채움). 여러 개면 세미콜론(;) 구분 | `운전면허1종` |
| required_exp_years | 필수 경력연수(숫자) | "경력 N년 이상"처럼 숫자가 명확할 때만 채움. 없으면 빈칸 | `2` |
| experience_note | 필요경력(원문) | 공고의 "필요경력"을 그대로 옮김 | `경력무관` |
| physical_load | 신체강도 | 상/중/하 중 공고나 담당자 판단으로 입력. 근거 없으면 빈칸(빈칸이면 앱이 감점하지 않음) | `중` |
| education | 필요학력(원문) | 공고의 "필요학력"을 그대로 옮김 | `고등학교 이상` |
| gender_note | 성별제한(원문) | 공고의 "성별제한"을 그대로 옮김. 앱이 판단 근거로 쓰지 않음 | `여성만 지원가능` |
| age_note | 연령제한(원문) | 공고에 실제로 적은 연령 관련 문구만 옮겨 적음. 앱은 이 값을 이유로 추천에서 제외하지 않음 | `65세 미만 지원가능` |
| job_description | 직무내용(원문) | 공고의 "구인직무" 중 직무명(job_title) 이후 상세 설명을 그대로 옮김. 상담 화면에 참고용으로 표시됨 | `건물 미화` |
| qualification_note | 자격요건(원문) | 공고의 "자격요건"을 그대로 옮김. `required_license` 판단 근거를 원문으로 확인할 때 씀 | `요양보호사 자격증 보유 필수` |
| preference_note | 우대사항(원문) | 공고의 "우대사항"을 그대로 옮김. `preferred_license` 판단 근거를 원문으로 확인할 때 씀 | `치매전문교육 수료자 우대` |
| work_condition | 근무조건(원문) | 공고의 "근무조건"을 그대로 옮김 (4대보험 가입 여부 등) | `4대보험 가입` |
| homepage | 홈페이지(원문) | 공고의 "홈페이지"를 그대로 옮김 | `www.example.com` |
| etc_note | 기타 특이사항 / 확인 필요 메모 | 자유 입력. 원문이 불확실할 때 `[확인필요]`로 시작하는 메모를 남기면 앱 목록에서 눈에 띕니다 | `4대보험, 중식제공` |
| status | 당일 모집 상태 | `모집중` 또는 `당일마감` | `모집중` |

## 직무군(job_family) 4분류

참여기업 등록 자료의 "업종" 대분류를 그대로 사용합니다(=`industry`와 동일한 값). 행사 부스 구역(A/B/C/D 코드)도 이 분류를 그대로 따릅니다.

| 값 | 예시 직무 |
|---|---|
| 조리·돌봄·시설관리 | 요양보호사, 아이돌봄사, 산후관리사, 경비, 미화, 조리 |
| 사무·행정·운영지원 | 총무, 경리, 사무보조, 행정지원 |
| 교육·서비스·영업 | 강사, 상담·컨설팅, 영업, 마케팅, 판매 |
| 운송·물류·제조 | 운전원, 배송, 물류, 생산직 |

## 데이터 갱신 방법 (요약, 자세한 절차는 README 참고)

1. `data/companies.csv` 파일을 Excel이나 메모장으로 열어 수정·저장합니다.
2. `index.html`을 연 상태에서 화면 상단의 **"기업 데이터 불러오기"** 버튼을 눌러 방금 저장한 `companies.csv` 파일을 다시 선택합니다.
3. 화면의 목록이 즉시 갱신됩니다. (인터넷 연결이나 재설치가 필요 없습니다.)
