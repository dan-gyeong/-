# 중장년 채용박람회 현장상담 매칭 프로그램 - 사용설명서

프로그래밍 지식이 없어도 사용할 수 있도록 만들어졌습니다. 이 문서 순서대로 따라 하세요.

## 1. 실행 방법

1. `job-fair-matching-app` 폴더 전체를 노트북/데스크탑에 복사합니다. (USB로 복사해도 됩니다.)
2. 폴더 안의 `index.html` 파일을 **더블클릭**합니다. 기본 웹브라우저(크롬 권장)로 열립니다.
3. 인터넷 연결이 없어도 정상 동작합니다. 별도 설치나 서버 실행이 필요 없습니다.
4. 맨 처음 열면 "운영관리" 탭으로 가서 **기기코드**를 먼저 설정해야 상담 화면을 쓸 수 있습니다 (아래 3장 참고).

**주의**: 인터넷 익스플로러(IE)는 지원하지 않습니다. 크롬, 엣지, 파이어폭스 등 최신 브라우저를 사용하세요.

## 2. 화면 구성

- **상담 매칭**: 내담자 상담 시 사용하는 기본 화면. 조건 입력 → 추천 결과 → 인쇄.
- **간편 상담신청**: 후속 상담을 원하는 내담자의 연락처 등을 접수하는 화면. PIN 필요.
- **운영관리**: 기기코드 설정, 데이터 불러오기/내보내기, 모집상태 관리, 컨설턴트 명단 등.

## 3. 기기코드 설정 (8대 운영 시 반드시 필요)

- 노트북 6대는 `L1`~`L6`, 데스크탑 2대는 `D1`~`D2` 중 하나를 각 기기에 **한 번씩** 배정합니다.
- 운영관리 탭 상단에서 해당 기기 버튼을 누르면 설정됩니다. 화면 우상단에 항상 크게 표시됩니다.
- 기기코드를 설정하기 전에는 "상담 매칭" 탭이 잠겨 있습니다.
- 실수로 잘못 눌렀다면 운영관리 탭의 "기기코드 초기화" 버튼으로 다시 설정할 수 있습니다.
- 세션번호는 `기기코드-순번` 형식(예: `L3-0042`)으로 자동 발급되어, 8대를 나중에 합쳐도 번호가 겹치지 않습니다.

### 기기 역할 배치(권장, 강제 아님)
데스크탑 2대는 전원·유선망이 안정적이므로 그중 1대(`D1`)를 아래 4장의 "마감정보 공유" 운영석으로 두는 것을 권장합니다. 실제 배치는 현장 상황에 맞게 결정하세요.

## 4. 기업(직무) 데이터 갱신

행사 전 참여기업 목록이 바뀌면:

1. `data/companies.csv`를 Excel이나 메모장으로 열어 수정·저장합니다. (열 설명은 `data/schema.md` 참고)
2. `index.html`을 이미 열어 둔 상태라면, **운영관리 탭 → "기업 데이터 불러오기"**에서 방금 저장한 파일을 다시 선택합니다.
3. 목록이 즉시 갱신됩니다.

이 프로그램은 `file://`로 여는 단일 페이지이기 때문에, 브라우저 보안 정책상 폴더의 파일을 자동으로 계속 읽어올 수 없습니다. 그래서 "파일 선택" 버튼으로 직접 불러오는 방식을 씁니다 - 8대 모두에서 **각자** 최신 `companies.csv`를 불러와야 합니다.

한글문서(HWP)나 PDF로 된 채용공고 모음뿐이라면, 사람이 직접 `companies.csv`에 옮겨 적는 것이 가장 정확합니다. `data/schema.md`의 표를 참고하세요. **공고에 없는 값은 절대 추측해서 채우지 마세요.** 모르면 빈칸으로 두면 화면에 "정보 없음"으로 자동 표시됩니다.

엑셀(.xlsx) 원본이 있다면 `tools/convert.py`로 변환할 수 있습니다 (7장 참고).

## 5. 상담 진행 순서 (상담사용)

1. "상담 매칭" 탭 → "상담 시작" 클릭 → 세션번호 자동 발급 (이름/연락처 입력 없음)
2. 내담자와 대화하며 조건을 클릭으로 입력 (자유입력 최소화, 약 90초 목표)
3. "우선순위 지정"에서 내담자가 가장 중요하게 여기는 항목 1~3순위를 순서대로 클릭
4. "매칭 결과 보기" 클릭 → 상위 6개 추천 카드 확인
5. 필요하면 지역·고용형태 필터나 가중치 슬라이더로 즉시 재조정
6. 카드의 "부스에서 물어볼 것"을 내담자에게 안내
7. 배부할 기업만 체크박스를 켠 채로 "내담자 배부용 요약 인쇄" 클릭
8. 후속 상담을 원하면 "간편 상담신청 접수" 버튼으로 이동해 접수 (6장 참고)
9. 상담이 끝나면 "새 상담 시작"으로 다음 내담자를 맞이합니다

상담 내용은 개인식별정보 없이 자동으로 내부에 기록되며(운영관리 탭에서 CSV로 내보낼 수 있음), 별도 저장 버튼을 누르지 않아도 됩니다.

## 6. 간편 상담신청 (후속 상담 접수)

- "간편 상담신청" 탭은 **4자리 PIN**으로 보호됩니다. 이 기기에서 처음 사용할 때 PIN을 설정하고, 이후에는 매번 입력합니다.
  - **중요**: 이 PIN은 암호화가 아닙니다. 옆에서 화면을 훔쳐보는 것을 막는 수준의 장치일 뿐입니다. 실질적인 정보 보호는 **노트북 계정 잠금(로그인 비밀번호)**과 **디스크 암호화**(Windows BitLocker, macOS FileVault 등)에 의존합니다. 행사 전 IT 담당자에게 이 두 가지가 켜져 있는지 반드시 확인하세요.
- 저장 전 반드시 동의 문구를 보여주고 체크박스에 동의해야 저장 버튼이 활성화됩니다. 동의 문구는 `data/consent.txt`에서 불러온 내용이 **그대로** 표시됩니다 (앱이 임의로 문구를 만들지 않습니다).
- 명부 목록은 기본적으로 마스킹되어 표시됩니다(예: 홍○동 / 010-****-5678). 행을 클릭하면 잠깐 전체가 보입니다.
- 연락처 뒤 4자리가 같은 기존 신청이 있으면 저장 시 경고가 뜹니다. 자동으로 막지는 않으니, 동일인인지 확인 후 저장하세요.
- 배정은 프로그램이 후보만 제안하고, 실제 배정 확정은 담당자가 드롭다운에서 직접 선택해야 합니다 (자동 확정 없음).
- 매칭 상담 내용(비식별)과 신청자 명부(식별정보)는 완전히 분리된 저장소를 사용하며, 연결값은 세션번호뿐입니다. 상담요약 CSV에는 성명·연락처 열 자체가 없습니다.

## 7. `data/consent.txt` 및 `data/consultants.csv` 준비 (행사 전 필수)

배포된 파일은 **플레이스홀더**입니다. 반드시 실제 값으로 교체한 뒤 행사에 사용하세요.

- `data/consent.txt`: 기관이 확정한 개인정보 수집·이용 동의 문구와 보유기간을 `===CONSENT_TEXT===` / `===RETENTION_TEXT===` 구분선 형식 그대로 유지하며 채워 넣습니다. 채운 뒤 운영관리 탭에서 파일을 다시 불러오세요.
- `data/consultants.csv`: 실제 배정 대상 컨설턴트의 성명, 전문 직무군, 담당 지역, 1일 배정 상한으로 수정합니다. Excel로 열어 편집 후 저장하면 됩니다. 운영관리 탭에서 다시 불러오세요.

## 8. 엑셀 변환 도구 (`tools/convert.py`, 선택 사항)

참여기업 원본이 엑셀(.xlsx)이라면 companies.csv로 변환할 수 있습니다. 파이썬이 설치되어 있어야 합니다(추가 설치 라이브러리 불필요).

```
python3 tools/convert.py 원본파일.xlsx data/companies.csv
```

원본 열 이름이 표준과 다르면 `tools/convert.py` 안의 `HEADER_ALIASES` 표에 표현을 추가하면 자동 매칭됩니다. 매칭되지 않은 열은 빈칸으로 남으며, 실행 후 어떤 열이 비었는지 안내 메시지가 출력됩니다.

## 9. 다중 기기(8대) 운영과 병합

### 기본 운영: 완전 독립 실행
8대는 서로 통신하지 않고 각자 독립적으로 동작합니다. 한 대가 멈추거나 꺼져도 나머지 7대는 영향받지 않습니다.

### 행사 종료 후 병합
1. 각 기기의 "운영관리" 탭에서 **상담요약 CSV**를, "간편 상담신청" 탭에서 **신청자명부 CSV**를 각각 내보냅니다. (8대 × 2종 = 16개 파일)
2. 16개 파일을 한 폴더(USB나 기관 공유폴더)에 모읍니다.
3. 다음 명령으로 병합합니다:
   ```
   python3 tools/merge.py <파일들이 모인 폴더> <결과를 저장할 폴더>
   ```
4. 결과: 통합 신청자명부, 통합 상담요약 CSV 2개와 다음 요약이 화면에 출력됩니다.
   - 총 상담건수 / 기기별 건수
   - 총 신청건수 / 기기별 건수
   - 세션번호 중복이나 알 수 없는 기기코드 경고
   - 연락처 뒤 4자리 + 성명이 같은 **중복 신청 후보** (자동 삭제하지 않음 - 사람이 확인)
   - 같은 후보가 서로 다른 컨설턴트에 배정된 **배정 충돌** 표시

### 확장 모드(선택): 마감상태 공유
운영관리 탭에서 다음과 같이 사용합니다.
- **D1(운영석)**: 기업이 마감되면 "당일마감으로 전환" 후 "마감정보 내보내기"로 `status.csv`를 만들어 공유폴더/USB에 둡니다.
- **나머지 7대(상담용)**: "마감정보 불러오기"에서 그 `status.csv`를 선택하면 모집상태만 반영됩니다. 반영 시각이 화면에 표시되고, 30분 넘게 갱신되지 않으면 경고가 뜹니다.
- 신청자 명부는 이 방식으로 **절대 공유되지 않습니다**. 공유되는 것은 기업 모집상태뿐입니다.
- 이 방식이 수동 버튼인 이유: `file://`로 연 단일 HTML 페이지는 브라우저 보안 정책상 공유폴더를 자동으로 주기적으로 읽을 수 없습니다. 브라우저 보안 설정을 바꾸거나 별도 서버를 구동하는 방법은 일부러 쓰지 않았습니다(둘 다 현장 운영에는 위험 부담이 더 큽니다).

**비기술적으로 미리 정해둘 것 (행사 전 회의에서 결정)**
- 기업 부스가 마감을 운영석에 알리는 방법과 담당자(예: 무전기, 문자, 직접 방문)
- 마감정보 갱신 주기(예: 매시 정각에 상담용 기기들이 "마감정보 불러오기" 실행)
- 갱신이 늦을 수 있으므로, 상담 화면에는 "모집상태는 부스에서 최종 확인 필요"라는 문구가 항상 표시됩니다. 내담자에게도 이 점을 안내하세요.

## 10. 개인정보 처리 및 행사 종료 후 절차

- 모든 데이터는 해당 기기의 브라우저 안에만 저장됩니다(localStorage). 외부 서버로 전송되지 않습니다.
- 비식별 상담 세션 데이터와 식별정보가 있는 신청자 명부는 **서로 다른 저장 공간**에 있고, **삭제 버튼도 각각 따로** 있습니다.
  - 세션 데이터 삭제: 화면 상단 "세션 데이터 전체 삭제" (모든 탭에서 항상 보임)
  - 신청자 명부 삭제: "간편 상담신청" 탭 → "명부 삭제" (재확인 절차 있음)
- **행사 종료 후 절차 (8대 모두 순서대로 진행)**
  1. 각 기기에서 상담요약 CSV, 신청자명부 CSV를 내보냅니다.
  2. 기관이 지정한 위치(USB/공유폴더)로 옮기고 `tools/merge.py`로 병합합니다.
  3. 내보내기가 확인되면 8대 **전부**에서 "세션 데이터 전체 삭제"와 "명부 삭제"를 각각 실행합니다.
  4. 기기별 삭제 확인 체크리스트를 작성합니다(아래 표를 인쇄해 사용하세요).

| 기기코드 | 상담요약 내보내기 | 신청자명부 내보내기 | 세션 데이터 삭제 | 명부 삭제 | 확인자 |
|---|---|---|---|---|---|
| L1 | ☐ | ☐ | ☐ | ☐ | |
| L2 | ☐ | ☐ | ☐ | ☐ | |
| L3 | ☐ | ☐ | ☐ | ☐ | |
| L4 | ☐ | ☐ | ☐ | ☐ | |
| L5 | ☐ | ☐ | ☐ | ☐ | |
| L6 | ☐ | ☐ | ☐ | ☐ | |
| D1 | ☐ | ☐ | ☐ | ☐ | |
| D2 | ☐ | ☐ | ☐ | ☐ | |

## 11. 문제 발생 시 대처

| 증상 | 대처 |
|---|---|
| 상담 화면이 잠겨 있음("기기코드를 먼저 설정하세요") | 운영관리 탭에서 기기코드를 설정하세요. |
| 기업 데이터가 예전 것으로 보임 | 운영관리 탭에서 최신 `companies.csv`를 다시 불러오세요. |
| 마감 처리한 기업이 다른 기기에는 그대로 "모집중"으로 보임 | 정상입니다(8대는 독립 동작). 확장모드(9장)로 "마감정보 불러오기"를 실행하거나, 상담 시 "모집상태는 부스에서 최종 확인 필요" 문구대로 현장에서 재확인하세요. |
| 인쇄가 안 됨 | 브라우저의 인쇄 팝업이 차단됐을 수 있습니다. 브라우저 설정에서 팝업 차단을 해제하세요. |
| PIN을 잊어버림 | 이 기기에서 PIN은 브라우저 저장소(localStorage)에만 있습니다. 브라우저 개발자에게 문의하거나, 최후의 수단으로 브라우저 사이트 데이터를 초기화하면 PIN뿐 아니라 이 기기의 모든 데이터(세션·명부)가 함께 사라지므로, 먼저 CSV로 내보낼 수 있는지 확인한 뒤 진행하세요. |
| 실수로 다른 사람 명부가 보임(마스킹 해제 상태) | 해당 행을 다시 클릭하면 재마스킹됩니다. |
| 파일을 열었는데 화면이 깨져 보임 | 최신 크롬/엣지 브라우저로 여세요. 글자가 깨지면 파일이 손상되지 않았는지 다시 복사해보세요. |

## 13. 알려진 한계 및 남은 준비 사항

- `data/companies.csv`에 담긴 11개 기업 데이터 중 일부는 원본 이미지 판독이 어려워 직무명·근무지 등이 비어 있거나 `[확인필요]` 표시가 붙어 있습니다. 행사 전 원본 공고로 재확인해 채워 넣으세요.
- `data/consent.txt`, `data/consultants.csv`는 플레이스홀더입니다. 실제 값으로 교체하지 않으면 안내 문구가 그대로 노출되니, 행사 전 반드시 교체하세요.
- 우선순위 지정은 스펙상 "드래그 정렬"로 요청되었으나, 여러 기종(터치스크린 포함)에서 안정적으로 동작하도록 "클릭한 순서대로 순위 부여" 방식으로 구현했습니다. 결과는 동일합니다(내담자가 지정한 3개 우선순위가 그대로 반영됨).
